# الموقع التسويقي — tijaracrm.com

موقع ثابت (HTML + CSS + JavaScript) بدون أي مكتبات أو خطوة بناء. يخدمه Nginx مباشرة من `public/`، ويتواصل مع الـ backend عبر `/api/public` فقط (العقد الكامل في [`API.md`](API.md)).

## الصفحات

| الصفحة | الوظيفة |
|---|---|
| `index.html` | الرئيسية: المزايا، الفاتورة الإلكترونية، الأسعار (من الـ API)، الخدمات التقنية، طلب عرض سعر، الأسئلة |
| `signup.html` | التسجيل في التجربة المجانية (أو `?subscribe=1` للاشتراك المباشر) مع فحص توفر الرابط |
| `verify.html` | إدخال رمز التحقق المرسل بالبريد |
| `setup.html` | متابعة تجهيز بيئة العميل حتى تصبح جاهزة |
| `checkout.html` | اختيار الباقة والفوترة والدفع عبر Moyasar (يتطلب `?token=`) |
| `payment-result.html` | تأكيد الدفع من السيرفر بعد الرجوع من Moyasar |
| `terms.html` `privacy.html` `refund.html` | مسودات قانونية تحتاج مراجعة مستشار |

## اللغتان (العربية والإنجليزية)

- **المصدر:** النص العربي داخل الصفحات هو المصدر.
- **الترجمة:** `public/assets/i18n.js` يحمل قاموس الإنجليزية، ويستبدل النصوص عند اختيار English، ويقلب اتجاه الصفحة إلى اليسار.
- **تحديد اللغة:** `public/assets/lang-boot.js` يحدد اللغة قبل رسم الصفحة لتجنب الوميض. الأولوية: `?lang=en` في الرابط، ثم الاختيار المحفوظ، ثم العربية.
- **زر التبديل:** موجود في رأس كل صفحة.
- **عند إضافة نص عربي جديد:** أضف ترجمته في القاموس، وإلا يبقى عربيًا في النسخة الإنجليزية. للتحقق، افتح الصفحة بـ `?lang=en` ونفّذ `TC_I18N.missing()` في console المتصفح.
- **إلى الـ API:** كل طلب يرسل ترويسة `Accept-Language: ar|en`.

## الإعدادات

`public/assets/config.js`: مسار الـ API، ورابط portal، ومفتاح Turnstile العام، ورابط مكتبة Moyasar، وبيانات التواصل.

- يُقرأ دون تخزين مؤقت، فتعديله على السيرفر يسري فورًا.
- **لا يحتوي أي مفتاح سري.**

## التجربة محليًا

```bash
node dev/mock-api.js
# افتح http://localhost:8090
```

- **الخادم الوهمي:** يحاكي كل الـ API وMoyasar.
- **رمز التحقق:** دائمًا `123456`.
- **أسماء مأخوذة أو محجوزة للتجربة:** `portal` و`admin` و`alawwad`.
- **الرابط `failme`:** يحاكي فشل التجهيز.
- **صفحة دفع تجريبية:** `/checkout.html?token=demo`.
- **محاكاة فشل الدفع:** اختيار الباقة الأساسية.
